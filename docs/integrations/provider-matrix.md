## Maturity rules

- **0 — Researched:** official surface and prerequisites documented.
- **1 — Adapter contract:** capability and normalization contract exists in this app.
- **2 — Configurable:** environment variables and callback/setup instructions exist.
- **3 — Authenticated:** a real user authorization/permission flow completes.
- **4 — Data verified:** a real account/device read is normalized, persisted, and visible with provenance.
- **5 — Production ready:** refresh, disconnect, retries, rate limits, observability, privacy review, and automated contract tests are complete.

The current app should show 0–2 honestly until server credentials, callback URLs, native builds, and real test accounts are available. The browser must show **Android required** for Health Connect and **Approval required** for Garmin/Samsung where appropriate; it must not show a simulated connected state.
